反无训练栈选型
这一页只看训练栈，不比较单个仿真器

训练栈要回答的是：环境怎么组织、采样怎么并行、19-D 特征怎么接、PPO 怎么训、策略怎么回到 PX4。 同一个仿真器可以被不同训练栈使用；同一个训练栈也可以换仿真后端。这一页只比栈的组织方式， 仿真器的气动/相机/PX4 细节在另一页。

9 套训练栈 19-D 特征 PPO PX4 部署 只比训练栈

00训练栈的五个部件

先把「训练栈」拆开。它不是一个仿真器，也不是一个 PPO 脚本，而是下面五段的组合。

术语：RSL-RL 是什么 RSL-RL 是 ETH Zurich RSL 的轻量 PyTorch RL 库（BSD-3，论文 arXiv:2509.10771），主打 PPO + student-teacher distillation、多 GPU、代码量小。 它是「学习器」，不是仿真器，也不是飞控：Isaac Lab、mjlab、MuJoCo Playground 都拿它当默认 PPO 训练器。 你的 19-D → 3-D 动作可以直接喂给它，但它不负责 Gazebo/ROS/PX4；在 Gazebo 栈里用，需要自己写 Gym wrapper，或保留你现在的 PPO。
关键 训练栈的差异，主要不在「PPO 算法」，而在环境接口、并行方式、感知接入、部署闭环这四件事。 19-D MLP 本身不是瓶颈；瓶颈是 env/s、特征质量和 sim2real。

02三种运行模式，不要用一个栈硬扛

训练模式

目标：19-D 特征上的 PPO 大规模迭代。

栈：Isaac Lab + RSL-RL / MuJoCo+MJX + Brax。

关键：特征噪声、漏检、延迟、风扰；不渲染照片。

系统模式

目标：PX4 SITL/HITL、MAVLink、两机同步、offboard。

栈：Gazebo Sim + PX4 + PPO 推理节点 / RflySim。

关键：时序、飞控参数、执行器延迟；不在这里做大规模 PPO。

视觉模式

目标：YOLO v11 数据、虚拟平面误差、检测延迟。

栈：RflySim / AirSim / UE5 + YOLO。

关键：相机内参、FOV、运动模糊；图像不进入 PPO 训练循环。

为什么不能一个栈全包 训练模式要 GPU 并行和特征噪声；系统模式要 PX4 实时闭环；视觉模式要照片级渲染。 三者的节拍和硬件不同，塞进一个循环只会互相拖慢。它们共用 19-D 契约，但不共用同一个执行循环。

03给你的推荐组合

阶段训练栈为什么验收指标
主训练 Isaac Lab + RSL-RL + 自定义固定翼气动；或 MuJoCo/MJX + Brax/RSL-RL GPU 并行、19-D 特征、域随机化；先把 PPO 的样本效率提上来 env/s、样本效率、命中率、初始几何泛化
系统闭环 Gazebo Sim + PX4（advanced_plane / x500）+ PPO 推理 MAVLink、offboard、两机同步、HITL；保留真实飞控链路 offboard 切换、指令延迟、两机时钟偏差
视觉验证 RflySim / AirSim / UE5 + YOLO v11 照片级图像验证二阶矩/虚拟平面；不参与 PPO 大规模训练 mAP、s1/s2 误差、漏检率、延迟
气动复核 JSBSim + Gym + PPO（或 FlightGear 可视化） 高保真气动对照，确认简化模型没把策略带偏 配平误差、失速边界、风扰响应
Intruder Aerial Gym / Flightmare（旋翼） 旋翼目标的大规模 RL 或脚本化飞行；与 defender 分开训练 旋翼策略成功率、规避行为

04让这些栈共用一套契约

训练栈可以换，但下面这些东西不能变。否则每换一个栈，任务就要重写一遍。

counter_uav/ ├── scenario.yaml # 初始几何 / 风 / 相机 / 检测噪声 / PPO 配置 ├── contracts/ │ ├── observation.py # 19-D 字段、顺序、归一化、坐标系、时间戳 │ └── action.py # acc / pitch / yaw 范围、限幅、history ├── sims/ │ ├── gazebo/ # 系统模式 │ ├── isaac/ # 训练模式 │ └── jsbsim/ # 气动复核 ├── perception/ │ ├── yolo_node.py │ └── virtual_plane.py ├── policy/ │ ├── train_ppo.py │ └── policy_node.py ├── launch/system.launch.py └── eval/metrics.py

这套契约的详细解释在 训练栈是怎么「统一」的。
