反无仿真器选型
这一页只看仿真器，不看 PPO 用哪个库

约束来自你的任务：固定翼 defender、旋翼 intruder、单目 YOLO、PX4 SITL/HITL、两机对抗。 仿真器要回答的是：气动够不够真、PX4 能不能闭环、相机能不能生成可信图像、多机能不能同步。 训练栈怎么组织，是另一页的事。

19 个仿真器/平台 固定翼 + 旋翼 PX4 SITL/HITL 只比仿真器

00四个硬约束

① 固定翼气动

不是「有没有固定翼模型」，而是「失速、侧滑、风切变、舵面延迟下，拦截控制还成不成立」。Gazebo 的 advanced_plane + Advanced Lift Drag / AVL 是底线；JSBSim / FlightGear / X-Plane 是参考系。

② PX4 SITL / HITL

你要的是两架 PX4：defender 固定翼 + intruder 旋翼，MAVLink、offboard、时钟同步都要通。没有 PX4 接口的仿真器，只能做算法原型，不能做系统闭环。

③ 单目相机

YOLO 的输入质量取决于 FOV、内参、曝光、运动模糊、纹理和延迟。照片级渲染不是「好看」，而是让二阶矩和虚拟平面误差可测。

④ 多机与吞吐

两机只是下限；你还会做初始几何扫描、风扰、检测噪声。仿真器要能稳定跑多实例，最好能批量并行，否则实验周期会被排队吃掉。

02按角色选，不选「全能冠军」

系统闭环 / 多机 / HITL

Gazebo Sim：PX4 + advanced_plane + 旋翼 intruder，两机、MAVLink、offboard 都能验证。

RflySim：预算允许时，PX4 + UE + 固定翼配置更接近工程闭环。

气动基准 / 控制复核

JSBSim + FlightGear：配平、失速、侧滑、风扰的参考系；FlightGear 提供可视化。

X-Plane：商业固定翼/视觉验证，PX4 SITL 可接。

视觉数据 / YOLO 验证

RflySim / AirSim / UE5：照片级图像、相机内参、天气；FlightGoggles 也可做纯视觉。

Gazebo 相机：只做集成 baseline，不要指望它生成训练级图像。

GPU 仿真 / 大规模 PPO

Isaac Lab：RTX 相机 + GPU 并行；固定翼气动要自己补。

MuJoCo/MJX：控制仿真快；视觉弱，固定翼模型自己写。

旋翼 intruder

Aerial Gym / Flightmare / PyBullet：四旋翼大规模 RL 或快速原型。

它们不能训练固定翼 defender，别拿来做主栈。

通用机器人 / 教学

Webots / CoppeliaSim：ROS 2、传感器、插件丰富，但飞行动力学不专。

适合验证感知/控制接口，不适合做主训练平台。

03选择顺序

先问如果是选如果不是
需要 PX4 SITL/HITL 吗？是Gazebo Sim / RflySim / XTDrone可看 Isaac Lab / MuJoCo / JSBSim
固定翼气动要可信到失速/风扰吗？是advanced_plane + AVL；JSBSim / FlightGear / X-Plane 复核Gazebo 默认模型可先跑通
需要照片级 YOLO 数据吗？是RflySim / AirSim / UE5 / FlightGogglesGazebo 相机做 baseline
需要万级并行 PPO 吗？是Isaac Lab / MuJoCo/MJX（固定翼自定义）Gazebo/RflySim 单实例即可
只训练旋翼 intruder 吗？是Aerial Gym / Flightmare / PyBullet不要用旋翼专用仿真器训 defender
不要做的事 不要用 Gazebo Classic 开新项目（已 EOL）；不要指望 AirSim 原生支持固定翼；不要用 Aerial Gym 训练固定翼 defender； 不要把「能加载固定翼模型」当成「气动可信」。
