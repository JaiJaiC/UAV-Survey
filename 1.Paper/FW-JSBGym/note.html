2. 洞察与创新

2.1 核心洞察

🎯 把"哪个算法好"翻译成"建模假设与环境是否同构"
为什么此前没人做过这个对比？因为两个社区的评价体系不兼容：MF-RL 的度量是"相同步数下谁飞得好"，MB-RL 的度量是"达到同等性能需要多少真实交互"，后者根本不做同预算横评。要让两派同台，必须先把"预算"这个坐标系统一——本文让所有 agent 都跑 750k 步，再用一个被精心调过的 PID 卡住下界。看似平常，却是整个领域此前缺的地基。
最关键的想法是把笼统的"算法优劣"拆成三条正交的轴：轴一，动力学的确定性程度——确定性但强非线性的大姿态区，TD-MPC 的"显式模型 + 在线规划"完胜；随机湍流下它的确定性隐模型被误设，优势消失。轴二，MDP 是否成立——湍流仍存在"时间平均 MDP"，阵风则让转移函数在时间上不再有定义。轴三，奖励是否只含跟踪误差——对控制增量零惩罚，最优策略必然落在动作多面体的顶点上（bang-bang）。
为什么别人没这么做？需要三件事同时成立：能产生常值风/Dryden 湍流/离散阵风的高保真固定翼仿真器（JSBSim 原生支持，PyFly 不支持阵风）；把风扰动与参考难度解耦的实验设计（风实验只在 nominal 参考上跑）；足够强且被公平调参的 PID 基线（作者在无风下重调了 Bøhn 的增益）。缺一条，结论就会被"仿真器不真/难度混淆/基线太弱"击穿。本文的创新不在算法，而在这三件事同时做对了。

2.3 与已有工作的本质差异

维度已有工作本文
对比对象"单一 RL vs PID"，或"MB-RL 采样效率 vs MF-RL"三类同台：PID + PPO/SAC + TD-MPC，4 个基础 agent、7 个变体（含 AVP/CAPS）
训练预算各家不同（按收敛/墙钟），横向不可比硬性统一 750k 步，把预算这个自由度锁死
扰动建模把"风扰动"当整体，或只测湍流常值风 / Dryden 湍流 / 离散阵风三者分离，各分 4 档强度
评价指标几乎只看跟踪 RMSERMSE + Act Fluct 双指标，后者直接对应舵机磨损与能耗
理论解释只报告"更好/更差"给出机理归因：阵风失败 = MDP→非平稳 POMDP 的形式化坍塌；湍流可学 = 时间平均 MDP 仍存在

创新点 1：TD-MPC 首次用于变化风况下的固定翼姿态控制

【做法】TD-MPC2 实现（MPPI 迭代 6 次、512 条候选、64 条精英、24 条策略先验、视界 H=3、温度 0.5），2 维舵面动作，观测与奖励同 PPO/SAC，唯一区别是"动作前多一步在线规划"。
【结果】nominal 3.81×10⁻²（PID 4.20、PPO 5.29、SAC 6.64），hard 9.10×10⁻²（PID 20.10、PPO 15.78、SAC 11.15）——两种区制都第一，且 hard 下领先幅度从 10% 拉到 121%。

创新点 2：把执行器抖振变成一等指标，并给出两种不完美的解

【做法】Act Fluct（Eq.18）：对副翼/升降舵，算回合内相邻指令差绝对值均值，再对回合与通道平均。对策是奖励加 AVP（Eq.19）或策略损失加 CAPS 时序正则（Eq.20）。
【结果与反例】PID 0.07 → PPO 1.98、SAC 10.07、TD-MPC 4.37（差 28–144 倍）。AVP 对 TD-MPC/SAC 有效（0.54/0.50）却让 PPO 更抖（13.78）甚至不收敛；CAPS 对 MF-RL 稳定有效（PPO 1.47、SAC 0.53）但对 TD-MPC 原理上无效——TD-MPC 从不直接采样策略先验出动作。

创新点 3：把"扰动类型"升为与"算法选择"并列的自变量

【做法】湍流用 Dryden 谱（连续随机），阵风用 JSBSim 离散模型（每回合固定步触发，上升 0.25 s / 保持 0.5 s / 消退 0.25 s，余弦过渡），分别训练测试且只在 nominal 参考上做。
【结果】湍流下 TD-MPC ≈ PID ≈ PPO（扰动强度主导）；阵风下 TD-MPC 甚至略逊于 PPO 与 PID，SAC 全面垫底。由此提出：阵风使 P(s'|s,a) 在某些时刻根本不存在，产生状态混叠。

3.3 模块要点

① 双频架构。agent_frequency（控制器，100 Hz）与 fdm_frequency（物理积分）解耦，sim_steps_after_agent_action = fdm//agent；step() 先 apply_action() 再跑 N 次 sim.run_step()。论文中两者相同（dt=0.01 s），但设计允许"控制器 50 Hz + 物理 200 Hz"这类真机配置。

② 风场注入（L308–481）。set_atmosphere() 读 {wind, turb, gust} 三层配置，各有 enable 与 severity；severity 字符串 "off"/"light"/"moderate"/"severe" 映射到 0 / 25.2 / 54 / 82.8 kph——正好是论文 Table 8 的 0/7/15/23 m/s，最终乘 0.9115 转 ft/s（JSBSim 内部单位）。random_wind_vector(windspeed_limit=40.0) 在压扁的立方体 U([-1,-1,-0.1],[1,1,0.1]) 里采方向再归一化，故意压低垂直分量，避免不合物理的强上升气流。阵风三个时长常量（0.25/0.5/0.25 s）与 gust_frame=3（惯性 NED）写死在 set_atmosphere() 里，与论文 §6.2.2 一字不差。

③ 终止逻辑（重要）。is_terminated() 直接 return False，注释写着 "In the current MDP formulation, there's no terminal state." 唯一截断来自 is_truncated()：步数用尽，或观测越界（observation not in observation_space，说明 JSBSim 数值发散）。这与论文的 MDP 定义自洽——姿态调节没有"成功/失败"终态，只有"飞满 20 秒"与"数值爆炸"。

④ 空间自动生成。get_observation_space() 遍历 state_prps 的 min/max 造 Box；obs_is_matrix=True 时形状为 (1,hist,n) 供 CNN，否则 np.tile 成 hist×n 向量。本文用 MLP + 无历史（nohist）。

💡 把 state_prps 当成"这个 MDP 的定义文件"
论文 §4.2 的状态清单在这里被翻译成 14 个 BoundedProperty 的有序元组，而顺序就是观测向量的索引顺序——必须与 FW-FlightControl 里网络输入层的假设严格一致，否则训练静默失效。这也是 vanilla.py 每加一个状态都要重调 self.observation_space = self.get_observation_space() 的原因。

4. 任务定义——解决的问题是什么？

📐 带扰动的双通道姿态调节，不是轨迹跟踪
给定一架无方向舵的飞翼（Skywalker X8），只靠副翼 δa 与升降舵 δe，把滚转 φ 与俯仰 θ 跟到随机给定的 (φ_d, θ_d)；空速由独立 PI 环经油门维持；环境可叠加常值风、Dryden 湍流、离散阵风。指标是20 秒内平均 RMSE 与动作抖振。参考是阶跃式姿态设定值——没有位置、没有航向、没有时间约束，这决定了后文所有结论的适用范围。

5. 技术挑战——为什么困难？

五类困难，每条按同一模板回答：为什么在物理/数学上难、论文怎么绕、代价是什么。第三条最重要——本文许多"负面结论"本质上都是某种绕法的代价被实验暴露出来。

5.1 气动非线性 + 轴间耦合，使线性化控制器在原理上失效

为什么难$C_D,C_Y,C_L,C_l,C_m,C_n$ 是 $(\alpha,\beta,p_r,q_r,r_r,\delta_a,\delta_e)$ 的非线性函数。小姿态角附近可做小扰动线性化，PID 够用；一旦进入滚转 45–60°、俯仰 25–30°，升阻非线性与 $p$-$r$、$q$-$r$ 交叉耦合同时变大，解耦假设直接崩掉。更糟：X8 是飞翼、无方向舵，偏航只能靠副翼的 adverse yaw 被动耦合，$\beta$ 通道天然欠驱动。
怎么绕不改控制器结构，而改"模型从哪来"：MF-RL 用策略网络隐式吸收非线性；MB-RL 用 MLP 组显式拟合 $T$ 再规划；PID 则接受"线性假设失效"作为对照组被预期会退化。高明之处：让"非线性区性能下降"变成有理论预期、可比较的量，而不是一句模糊的"PID 不够好"。
代价放弃可解释性与稳定性证明（RL 无 Lyapunov 函数、无增益裕度）；必须仿真训练、sim-to-real 未验证；为让 PID 公平，作者专门在无风下重调增益（Table 1），但这套增益是为 nominal 调优的，在 hard 区可能并非 PID 最优——构成潜在比较偏差。

5.2 姿态参考与空速参考在物理上互相矛盾

为什么难升力 $L=\tfrac12\rho V_a^2 S C_L(\alpha,\delta_e)$：维持升力需要 $\alpha$ 与 $V_a$ 匹配——低速要大迎角（抬头），高速要小迎角（低头）。若把"期望俯仰"与"期望空速"当两个独立设定值下发，会出现"60 km/h + 低头 −20°"这种物理上不可同时满足的组合。
怎么绕把油门从动作空间拿走：agent 只出 2 维舵面，空速由所有控制器共享的 PI 环（$k_{pV}=0.5,k_{iV}=0.1$，参考 60 km/h）维持。姿态与速度在架构上解耦成两个时间尺度：PI 慢（油门一阶惯性 $T=0.2$ s）、姿态快（100 Hz）。
代价奖励里就没有空速项，agent 无从知道"为跟踪姿态牺牲空速"不可接受；PI 环是固定增益线性控制器，强风下自身会饱和/超调，而这部分误差被排除在评价之外（只评姿态 RMSE）。作者也承认"若控高度，外环会给出更自洽的期望姿态，但超出本文范围"。

5.3 RL 策略天然收敛到 bang-bang，抖振无法靠"多训一会"消除

为什么难奖励只惩罚姿态误差、对控制增量零惩罚。在这个"控制免费"的最优控制问题里，最优解倾向在动作边界间来回切换：对给定误差，最大舵量能最快压下去，而"平滑"牺牲收敛速度却不被奖励。Seyde et al. (2021) 已证明极值策略常常就是真最优。所以抖振不是"训练不充分"，而是"目标函数少一项"的必然结果。
怎么绕两条路并行：AVP 在奖励里加 $R_\delta$（改"目标"）；CAPS 在策略损失里加时序正则 $L_{TS}$（改"假设空间"的 Lipschitz 性质）。
代价AVP 引入 3 个新超参且对算法极度敏感：$(0.25,0.25,0.5)$ 让 TD-MPC/SAC 变好，却让 PPO 不收敛，最后为 PPO 单独调成 $(0.45,0.45,0.1)$；CAPS 对 MF-RL 有效但对 TD-MPC 原理上无效。最终没有任何方法把抖振压到 PID 水平（最好 0.50 vs 0.07，仍差 7 倍）。

5.4 阵风把 MDP 打碎成非平稳 POMDP——全文最深的一条

为什么难MDP 的合法性建立在 $P(s_{t+1}|s_t,a_t)=T(s_t,a_t)$ 存在且不随 $t$ 变之上。阵风同时破坏两点：（i）不可观测——状态里没有风，只有滞后的 $\alpha,\beta$；（ii）非平稳——0.25 s 内从 0 冲到 23 m/s，同一 $(s,a)$ 在"平静时刻"与"阵风时刻"落到完全不同的 $s'$。形式化：同一 $(s,a)$ 存在两个实验给出不同 $s'$，$T$ 不再是函数而是多值关系，加上随时间变化，即非平稳 POMDP（状态混叠，McCallum 1996）。
怎么绕不在算法上绕，而把困难本身作为发现报告：用"湍流 vs 阵风"对照，证明湍流下仍存在时间平均 MDP（RL 会退回其上），阵风下连平均 MDP 都没有；并用两个假设解释现象——① 状态混叠使函数近似器在阵风来临时发生方向相反的更新；② PPO 的 clip 像保险，限制矛盾更新的步长，故 PPO 在阵风下反而比 SAC/TD-MPC 稳。
代价等于承认"训练见过各种扰动 ⇒ 鲁棒"在阵风下失效，动摇大量 UAV RL 论文的方法论基础；作者只能把 RNN 信念状态、概率化 TD-MPC、鲁棒 RL、多模型 MDP 全推给 future work——本文提供诊断而非解；且诊断缺直接证据：没做"给 agent 喂风信息"的对照（尽管代码已写好），"状态混叠"仍是与现象一致但未被证伪的假说。
🔥 一个被论文放过、但仓库里躺着答案的实验
ac_bohn_nova.py 第 325–338 行已定义 ACBohnNoVaIErrWindOracleTask：在 14 维状态上追加三轴真实风速（total_windspeed_north/east/down_kph），变成 17 维。这正是验证"状态混叠假说"的关键对照——若阵风失败真由"风不可观测"造成，开"上帝视角"后 Severe gust 性能应显著回升。但论文完全没报告这个实验，正文、表格、图里都没有。对读者这是一个明确的可抢占空白：跑一遍就能把最核心的假说从"推测"变成"证据"。

5.5 评测本身的可复现性——预算、种子、超参三重陷阱

为什么难三个自由度会让结论失真：（i）预算——按墙钟比 MB-RL 吃亏，按收敛步数比 MF-RL 吃亏；（ii）随机性——单次运行方差常与算法差异同量级；（iii）实现——同算法不同代码库的差异可能超过算法差距。
怎么绕三管齐下：统一预算（全部 750k 步）、统一实现（CleanRL 单文件 + 官方 TD-MPC2）、统计口径（5 次运行的均值 ± SEM）。这是全文最扎实的部分。
代价统一预算反而抹掉了 MB-RL 的核心卖点：TD-MPC 被提出正因为样本效率高，给它和 PPO 一样的 750k 步等于放弃检验"谁更省样本"，全文无 learning curve；5 次运行只能刻画随机性，无置信区间/配对检验，Table 6 里 PPO hard 的 SEM 达 2.48，统计上并不显著；超参未系统扫描，"PPO+AVP 不收敛"很可能只是一次调参失败。
⚠️ 五条挑战串起来是一条主线
它们说的是同一件事：固定翼姿态控制的难度不在"动力学复杂"，而在"你以为在解 MDP，其实你在解一个你并不完全知道其形式的问题"。挑战一/二是模型复杂度（$T$ 非线性、约束耦合）；挑战三/五是目标与评测（奖励缺项、预算口径）；挑战四是问题本身是否成立（$T$ 是否存在）。本文的真正贡献，是把第四类问题第一次在固定翼 UAV 上明确提了出来——前三类此前都有人碰过。

6. 方法与关键公式

按"从物理到算法"组织：先给被控对象与风场（6.1–6.4），再给四类控制器目标（6.5–6.7），最后是两个指标与全部超参（6.8–6.9）。论文只写了 Eq.1–20，PPO/SAC 目标函数只给引用；为便于复现，本笔记补全标准形式并标注"论文未给出"。

6.1 运动学与刚体动力学（Eq.1–4）

Eq.(1)–(2) —— 位置与姿态运动学 $$ \dot{\mathbf{p}}=R^n_b(\mathbf{q})\mathbf{v},\qquad \dot{\mathbf{q}}=\frac{1}{2}\begin{bmatrix}0&-\boldsymbol{\omega}^{\top}\\ \boldsymbol{\omega}&-S(\boldsymbol{\omega})\end{bmatrix}\mathbf{q} $$
$\mathbf{p}=[x,y,z]^\top$ NED 位置  |  $R^n_b$ 机体系→NED 旋转矩阵  |  $\mathbf{v}=[u,v,w]^\top$、$\boldsymbol{\omega}=[p,q,r]^\top$ 机体线/角速度  |  $S(\cdot)$ 反对称阵  |  为什么用四元数：避免万向锁，$\dot{\mathbf{q}}$ 双线性、积分稳定。代码对应 conversions.py 的 euler2quaternion()，每步一次。
Eq.(3)–(4) —— 牛顿-欧拉方程 $$ m\dot{\mathbf{v}}+\boldsymbol{\omega}\times(m\mathbf{v})=R^{n}_{b}(\mathbf{q})^{\top}m\mathbf{g}_n+\mathbf{F}_{\text{prop}}+\mathbf{F}_{\text{aero}},\qquad I\dot{\boldsymbol{\omega}}+\boldsymbol{\omega}\times I\boldsymbol{\omega}=\mathbf{M}_{\text{prop}}+\mathbf{M}_{\text{aero}} $$
$m=3.3640$ kg；$I_{xx}=1.2290$、$I_{yy}=0.1702$、$I_{zz}=0.8808$、$I_{xz}=0.9343$ kg·m²  |  $\boldsymbol{\omega}\times I\boldsymbol{\omega}$ 是陀螺耦合项——正是它让三轴不可解耦，也是 PID 在大角速率下失效的物理根源  |  注意 $I_{yy}\ll I_{xx},I_{zz}$：飞翼俯仰惯量比滚转/偏航小一个量级，意味着俯仰通道"更轻"、更易被扰动。

6.2 风场与相对气流（Eq.5–9）

Eq.(5)–(7) —— 相对风速分解 $$ \mathbf{v}^b_r=\mathbf{v}^b_g-\mathbf{v}^b_w,\qquad \mathbf{v}^b_w=R^b_n(\mathbf{q})\mathbf{v}^n_{ws}+\mathbf{v}^b_{wg}=[u_r,v_r,w_r]^{\top},\qquad \boldsymbol{\omega}^b_r=\boldsymbol{\omega}^b-\boldsymbol{\omega}^b_w=[p_r,q_r,r_r]^{\top} $$
$\mathbf{v}^n_{ws}$ 惯性系常值风（确定性偏置） |  $\mathbf{v}^b_{wg}$ 机体系湍流（随机过程） |  关键：气动力只"看得见"相对气流，而控制器看不见风本身，只能从 $\alpha,\beta$ 的偏移间接推断"有风"——这是状态混叠的物理来源。阵风与湍流的区别不在公式里，而在 $\mathbf{v}^b_{wg}$ 的统计性质上：湍流是零均值平稳过程，阵风是突发非平稳事件。
Eq.(8)–(9) —— 空速、迎角、侧滑角 $$ V_a=\sqrt{u_r^2+v_r^2+w_r^2},\qquad \alpha=\tan^{-1}\!\left(\frac{u_r}{w_r}\right),\qquad \beta=\sin^{-1}\!\left(\frac{v_r}{V_a}\right) $$
$V_a$ 决定动压 $\tfrac12\rho V_a^2$、从而决定全部气动力量级  |  $\alpha$ 决定 $C_L,C_D,C_m$  |  $\beta$ 决定 $C_Y,C_l,C_n$  |  它们与 $\alpha,\beta$ 是"风"进入气动模型的唯一通道，也是 agent 观测里仅有的两个风相关分量。注意论文此处写作 $\alpha=\tan^{-1}(u_r/w_r)$（非常见的 $w_r/u_r$），这是作者的机体轴约定；实际由 JSBSim 按标准定义计算，此处记号值得读者留意。
湍流如何生成（论文文字，未给公式）：白噪声经 Dryden 谱成形滤波器 $H_{\text{Dryden}}(s)$（MIL-F-8785C，JSBSim 内建）。白噪声是"时间上完全不相关"的扰动，直接注入会给出无限加速度；滤波后才具有有限相关时间与指定功率谱。它是平稳各态历经过程——"时间平均 MDP"存在的数学支点（§7.4）。

6.3 气动力、力矩与推进（Eq.10–12）

Eq.(10)–(12) —— 气动力/力矩 $$ \mathbf{F}_{\text{aero}}=R^b_w(\alpha,\beta)\begin{bmatrix}-D\\Y\\-L\end{bmatrix},\qquad \begin{bmatrix}D\\Y\\L\end{bmatrix}=\tfrac12\rho V_a^2 S \begin{bmatrix}C_D(\alpha,\beta,q_r,\delta_e)\\C_Y(\beta,p_r,r_r,\delta_a)\\C_L(\alpha,q_r,\delta_e)\end{bmatrix} $$ $$ \mathbf{M}_{\text{aero}}=\tfrac12\rho V_a^2 S\begin{bmatrix}b\,C_l(\beta,p_r,r_r,\delta_a)\\ c\,C_m(\alpha,q_r,\delta_e)\\ b\,C_n(\beta,p_r,r_r,\delta_a)\end{bmatrix} $$
$\rho=1.156$ kg/m³（约 600 m）、$S=0.75$ m²、$b$ 翼展、$c$ 平均气动弦  |  注意每个系数的自变量不同：$q_r$ 同时进 $C_D$ 与 $C_L$，$p_r,r_r$ 进 $C_Y$，而 $C_l,C_n$ 又依赖 $\beta$ 与 $p_r,r_r,\delta_a$——没有任何通道真正独立，这就是"轴间耦合"的数学表达  |  $C_n$ 的自变量里只有 $\delta_a$、没有方向舵：X8 无方向舵，偏航只能靠 adverse yaw 间接控制，$\beta$ 通道本质欠驱动；$C_l$ 与 $C_n$ 共享同一组自变量，即 Dutch roll 耦合。
参数来源：Gryte et al. (2018) 的 CFD + 风洞拟合，最终以查表形式落在 x8.xml。推力（§3.2.3）：螺旋桨在尾部、与机体 x 轴对齐，故 $\mathbf{F}_{\text{prop}}=[T_p,0,0]^\top$；简化模型 $T_p=C\delta_t$、$C=5.9$。代价：真实推力是 $(V_a,\text{rpm})$ 的二元非线性，线性式在高速/大油门区会高估推力；仓库根的 prop_x8.txt（20 KB 推力表）说明 FDM 层其实用查表，线性式只是分析简化。

6.4 执行器动态与约束

Eq.(14') —— 舵面二阶伺服 + 速率/幅值限幅 $$ \frac{\delta(s)}{\delta^c(s)}=\frac{\omega_0^2}{s^2+2\zeta\omega_0 s+\omega_0^{2}},\quad \omega_0=100\ \text{rad/s},\ \zeta=\tfrac{1}{\sqrt{2}};\qquad |\delta|\le30^{\circ},\ |\dot{\delta}|\le200^{\circ}/\text{s} $$
$\omega_0\approx15.9$ Hz 带宽远高于控制带宽，故执行器动态在控制带宽内基本可忽略，但它仍是"指令 ≠ 实际"的来源  |  $\zeta=1/\sqrt2$ 巴特沃斯型，无超调  |  ±200°/s 才是硬约束：100 Hz 下每步最多 2°，即动作指令即使瞬间跳变，实际舵面也只能线性爬升——它天然是一阶低通，所以 Act Fluct（衡量指令抖振）会比实际舵面抖振更严重  |  油门为一阶惯性，$K=1$、$T=0.2$ s（比舵面慢 20 倍）。

6.6 PPO 与 SAC（论文引用，目标函数为补全）

Eq.(15') —— PPO-Clip（论文未给出，标准形式） $$ L^{\text{CLIP}}(\theta)=\mathbb{E}_{t}\Big[\min\big(\rho_t(\theta)\hat{A}_t,\ \mathrm{clip}(\rho_t(\theta),1-\epsilon,1+\epsilon)\hat{A}_t\big)\Big],\quad \rho_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{\text{old}}}(a_t\mid s_t)} $$
$\hat{A}_t$ GAE($\lambda{=}0.95$) 优势  |  $\epsilon=0.2$（Table 3） |  为什么这个裁剪在本文格外重要：§6.2.2 提出——正是 clip 让 PPO 在阵风下比 SAC/TD-MPC 稳。阵风造成"同一 $(s,a)$ 对应矛盾目标"，梯度方向来回翻转；clip 给每次更新上保险，把矛盾更新限制在信赖域内。这是把"算法细节"与"鲁棒性"连起来的漂亮猜想（虽未做消融）。其余超参：LR 3e-4、6 并行环境、rollout 2048、minibatch 32、batch 12228、熵 1e-2、价值 0.5。
Eq.(16') —— SAC 最大熵目标（论文未给出，标准形式） $$ J(\pi)=\sum_{t}\mathbb{E}_{(s_t,a_t)\sim\pi}\big[r(s_t,a_t)+\alpha\mathcal{H}(\pi(\cdot\mid s_t))\big],\qquad \mathcal{H}(\pi(\cdot\mid s))=-\mathbb{E}_{a\sim\pi}\big[\log\pi(a\mid s)\big] $$
$\alpha$ 温度（Table 4 中 entropy reg=0.2，固定不自动调节） |  为什么选 SAC：连续动作机器人任务的 SOTA，且策略更新方式与 TD-MPC 内部策略学习目标相似，对比更"干净"。 |  反直觉现象：最大熵理论上应抑制过早收敛到 bang-bang，但 SAC 的 Act Fluct 高达 10.07/12.00，是所有 agent 最抖的。可能原因：熵正则在训练时鼓励随机，执行时却用确定性均值，两者不一致；而 Q 在动作边界附近的高估把均值推向极值。 |  其余超参：buffer 1e6、batch 256、seed 5000、policy LR 3e-4、Q LR 1e-3、$\tau=5\times10^{-3}$、策略每 2 步更新。

6.7 TD-MPC：学一个模型，在潜空间里规划

Eq.(18') —— TOLD 训练损失（论文文字描述，标准形式补全） $$ \mathcal{L}_{\text{TOLD}}=\sum_t\big\|R_\Theta(z_t,a_t)-r_t\big\|^2+\sum_t\big\|d_\Theta(z_t,a_t)-\mathrm{sg}(h_\Theta(s_{t+1}))\big\|^2+\sum_t\big\|Q_\Theta(z_t,a_t)-\big(r_t+\gamma\,\mathrm{sg}(Q_{\bar\Theta}(z_{t+1},a_{t+1}))\big)\big\|^2 $$
$h_\Theta$ 编码器、$d_\Theta$ 潜动力学、$\mathrm{sg}$ stop-gradient、$\bar\Theta$ 目标网络（$\tau=0.01$） |  三项权重（Table 5）：reward 0.1、value 0.1、consistency 20、temporal 0.5——一致性项是奖励/价值项的 200 倍，说明 TD-MPC2 把"潜空间动力学要准"放在绝对优先位置。 |  为什么这决定了它在随机环境里失效：大姿态角区制下 $T$ 是确定可微映射，一致性损失能压到极低；一旦环境随机，同一 $(z_t,a_t)$ 映射到多个 $z_{t+1}$，一致性损失的最优解退化成"条件均值"，规划器据平均模型预判必然失效（§7.4）。
Eq.(17) —— 轨迹回报：终端价值 + 时域内累计 $$ \phi_{\Gamma}\triangleq\mathbb{E}_{\Gamma}\Big[\underbrace{\gamma^{H}Q_{\Theta}(z_H,a_H)}_{\text{终端价值，}Q_\Theta\text{ 估计}}+\underbrace{\sum_{t=0}^{H-1}\gamma^{t}R_{\Theta}(z_t,a_t)}_{\text{时域 }H\text{ 内累计}}\Big] $$
$z_t$ 潜状态（非原始 $s_t$） |  $H=3$（Table 5） |  这是 TD-MPC 区别于普通 MPC 的关键：普通 MPC 在 $H$ 步后截断（终端代价设 0 或手工终端集），TD-MPC 用学出来的无限时域价值函数补尾巴，从而用 3 步规划逼近无限时域最优。代入 $\gamma=0.99$：$\gamma^H=0.97$，97% 的回报权重压在终端 Q 上——所以它的性能其实极度依赖 $Q_\Theta$，规划只提供"未来 3 步的精细化修正"（§7.1 给出定量）。
Eq.(19') —— MPPI 动作分布更新（论文引用，权重公式补全） $$ w_i=\frac{\exp(\phi_{\Gamma_i}/\lambda)}{\sum_j\exp(\phi_{\Gamma_j}/\lambda)},\qquad \boldsymbol{\mu}\leftarrow\sum_i w_i\mathbf{a}^{(i)}_0,\qquad \boldsymbol{\Sigma}\leftarrow\sum_i w_i(\mathbf{a}^{(i)}_0-\boldsymbol{\mu})(\mathbf{a}^{(i)}_0-\boldsymbol{\mu})^{\top} $$
$N=512$ 候选、$\lambda=0.5$ 温度、$\mathbf{a}^{(i)}_0$ 只更新第一步的分布  |  实际执行：6 轮迭代、每轮 512 样本、取 64 条精英、其中 24 条来自策略先验 $\pi_\Theta$——"精英 + 策略先验"混合是 TD-MPC2 相对原版的重要改动，保证采样不完全脱离已学策略  |  为什么用采样而非梯度：舵面有硬限幅、模型是 MLP 黑箱，梯度法易撞边界；采样只需前向，天然处理非光滑约束。代价是每步 6×512=3072 次潜空间 rollout（见 §9 的实时性批评）。

6.8 两个"平滑化"手段：改奖励 vs 改正则

Eq.(20) —— AVP 动作变化惩罚（论文 Eq.19） $$ R_\delta=\mathrm{clip}\!\left(\frac{\tfrac12\sum_{j\in\{a,e\}}\big|\delta^c_j|_t-\delta^c_j|_{t-1}\big|}{\zeta_\delta},0,c_\delta\right),\quad R^{\text{AVP}}_t=-(R_\phi+R_\theta+R_\delta),\quad \zeta_\delta=2 $$
$\zeta_\delta=2$：因 $|\delta^c_t-\delta^c_{t-1}|\in[0,2]$，除以 2 正好归一到 [0,1]  |  $c_\delta$ 按算法分别调：TD-MPC/SAC 用 $c_\phi=c_\theta=0.25,c_\delta=0.5$；PPO 这组参数训练不收敛，改为 $c_\phi=c_\theta=0.45,c_\delta=0.1$  |  注意分量权重被重新分配：原 $c_\phi=c_\theta=0.5$（合计 1），加 AVP 后变成 $0.25+0.25+0.5=1$——跟踪误差权重被砍半。这解释了为什么 AVP 组 TD-MPC 的 RMSE 反而变好（3.81→3.58）：不是"更平滑所以更准"，而是奖励尺度变了、优化景观变了。 |  对 PPO 的处置：单独调成 $(0.45,0.45,0.1)$，平滑项权重只剩 0.1，本质等于放弃平滑约束，结果 Act Fluct 从 1.98 暴涨到 13.78。
Eq.(21) —— CAPS 策略平滑正则（论文 Eq.20） $$ L_{\text{CAPS}}=\lambda_{TS}L_{TS}+\lambda_{SS}L_{SS},\quad L_{TS}=\|\pi_\Theta(s_t)-\pi_\Theta(s_{t+1})\|_2,\quad L_{SS}=\|\pi_\Theta(s_t)-\pi_\Theta(\hat{s}_t)\|_2,\ \hat{s}_t\sim\mathcal{N}(s_t,0.01) $$
$L_{TS}$ 时序平滑（抑制抖振） |  $L_{SS}$ 空间平滑（抑制噪声过拟合） |  论文只用时序项（$\lambda_{TS}=0.05$，$\lambda_{SS}$ 未启用），理由是"给状态空间留高响应性余地"  |  为什么对 TD-MPC 无效：CAPS 正则化的是策略先验，而 TD-MPC 的执行动作来自 MPPI，策略只占 24/512 条采样。作者原话："applying CAPS led to learning a smooth action policy prior but did not guarantee smooth actions after the planning step." 正则化了一个不被执行的函数，当然没用。

6.9 两个评价指标

Eq.(22) —— Act Fluct 动作抖振（论文 Eq.18）与 RMSE $$ \xi(\pi)=\frac{1}{2}\sum_{j\in\{a,e\}}\frac{1}{E}\sum_{n=1}^{E}\left[\frac{1}{T}\sum_{t=1}^{T}\big|\delta_j|_t-\delta_j|_{t-1}\big|\right],\qquad \mathrm{RMSE}=\frac{1}{2}\big(\mathrm{RMSE}_\phi+\mathrm{RMSE}_\theta\big) $$
$\xi$ 单位是"归一化指令/步"，乘 100 Hz 即指令变化率，正比于舵机功耗与磨损  |  为什么值得单列：它把"RL 能否上真机"变成数——PID 0.07、最好 RL 变体（SAC+AVP）0.50，仍差 7 倍；100 Hz 下意味着舵机每秒多做 43 次满幅反向动作  |  局限：它衡量指令而非实际舵面，而 ±200°/s 的速率限制会把高频抖振滤掉一部分，真实磨损可能低于字面值（论文未讨论）。

7. 核心技术原理详解

四个"真正的技术内核"，讲到可复现的程度：(1) 终端价值为什么让 3 步规划等价于无限时域最优；(2) MPPI 的指数加权从哪来、温度 $\lambda$ 在控制什么；(3) 为什么抖振是奖励缺项的必然；(4) 湍流与阵风的信息论差别。论文对这四点只给结论或一句话解释，推导为本笔记补。

7.1 原理一：$H=3$ 的规划凭什么逼近无限时域最优

Eq.(24)–(25) —— 截断误差的量级（论文未展开） $$ J^{\infty}=\sum_{t=0}^{H-1}\gamma^{t}r(z_t,a_t)+\underbrace{\gamma^{H}V^{\pi}(z_H)}_{\text{被截断的尾巴}},\qquad \big|J^{\infty}-J^{H}_{\text{trunc}}\big|=\gamma^{H}\big|V^{\pi}(z_H)\big|\le\gamma^{H}\frac{r_{\max}}{1-\gamma} $$
普通 MPC 令 $V^{\pi}\equiv V_f$（手工设计）；TD-MPC 令 $V^{\pi}(z_H)\approx Q_\Theta(z_H,a_H)$（学出来）。用 $Q$ 代 $V$ 相当于不做期望、只用单样本——方差更大但省一次策略前向。
代入本文数值（$r\in[-1,0]$、$\gamma=0.99$、$H=3$）：尾巴量级上界 $=0.99^3\times\frac{1}{0.01}=0.9703\times100\approx\mathbf{97.0}$；而视界内累计上界 $=\sum_{t=0}^{2}0.99^t\approx\mathbf{2.97}$。终端项的绝对量级是视界内总和的 30 倍以上——所谓"规划"其实是在给一个"被 $Q$ 主导的回报"做微调，$H=3$ 不意味着"只往前看 3 步"，而是"用 $Q$ 看无限远、用 3 步做局部修正"。
🎯 这条推导解释了本文最核心的实验现象
若 TD-MPC 的性能主要由 $Q_\Theta$ 而非规划决定，它的强弱就完全归因到"$Q$ 学得准不准"，而 $Q$ 依赖 TOLD 潜空间动力学（一致性权重 20 = 奖励项的 200 倍）。于是两条实验结论变得自洽：
  • 确定性非线性（hard）：$T$ 确定可微，一致性损失能压到极低，$Q$ 准，TD-MPC 赢（9.10 vs 20.10）；
  • 随机扰动（湍流/阵风）：同一 $(z_t,a_t)$ 对应多个 $z_{t+1}$，一致性损失最优解退化为条件均值，$Q$ 估的是"平均动力学下的价值"，与真实分布不符，优势消失。
所以 TD-MPC 的失败不是"规划不够好"，而是"它学的是一个确定性的世界，但世界不是确定的"。这是全文最值得记住的一句。
由此可推出三个可检验预言（论文未验证，但逻辑必然，现有代码几小时可测）：① 把 $Q_\Theta$ 换成噪声 → 性能崩塌；② 把 $H$ 从 3 增到 10 → 提升很小；③ 把 $\gamma$ 从 0.99 降到 0.9（终端权重 0.97→0.73）→ 规划的作用显著上升。

7.2 原理二：MPPI 的指数加权从哪来，温度 $\lambda$ 控制什么

Eq.(26)–(27) —— 自由能形式的最优控制 → Gibbs 分布（源自 Williams 2015） $$ \rho^{*}=\arg\min_{\rho}\Big\{\mathbb{E}_{\tau\sim\rho}[S(\tau)]+\lambda\,\mathrm{KL}(\rho\Vert\rho_{\text{ref}})\Big\} \;\Longrightarrow\; \rho^{*}(\tau)=\frac{1}{Z}\rho_{\text{ref}}(\tau)\exp\!\Big(-\frac{S(\tau)}{\lambda}\Big) $$
$S=-\phi_\Gamma$ 轨迹代价  |  $\lambda$ 温度，权衡"代价"与"保守性"  |  $\rho_{\text{ref}}$ 上一轮高斯 $\mathcal{N}(\boldsymbol{\mu},\boldsymbol{\Sigma})$  |  为什么必须有 KL 项：没有它，最优解是把全部概率压到单条最优轨迹的 δ 函数——模型错一步就全盘皆输；KL 强制保留多样性，本质是对模型误差的鲁棒化。
推导：对 $\rho$ 求变分（$\sum\rho=1$ 用乘子约束），一阶条件给出 $\log\rho^*=\log\rho_{\text{ref}}-S/\lambda+\text{const}$，取指数即得。$Z$ 算不出来，但 MPPI 用蒙特卡洛绕过它：$\rho^*$ 就是以 $\rho_{\text{ref}}$ 为提议、权重 $\propto\exp(-S/\lambda)$ 的重要性采样分布，于是 Eq.19' 的 $w_i\propto\exp(\phi_i/\lambda)$。
$\lambda$权重形态行为与控制论含义
$\to0$退化为 one-hot等价贪心：直接抄最优样本的第一步动作，对模型误差零容忍
0.5（本文）中等尖锐，64 条精英里前几条主导精英化但非独裁，配合 $N=512$ 实际有效样本约 10–20 条
$\to\infty$趋于均匀等价纯随机搜索：完全不信回报，退化为随机采样
💡 一个可复现的调参直觉
$\lambda$ 应与"模型置信度"反向配套：模型越准（确定性、低噪声）→ 越该用小的 $\lambda$ 激进利用；越不准（随机、分布外）→ 越该用大的 $\lambda$ 保守。本文恰好提供了反例：所有实验都用同一个 $\lambda=0.5$，无论确定性（hard）还是随机（湍流/阵风）。从 Eq.27 看，湍流下 $\rho_{\text{ref}}$ 本应更宽，固定 $\lambda$ 会让权重过于尖锐，把采样预算浪费在"碰巧回报高但不可复现"的轨迹上——这是"自适应温度"这个改进方向的依据。

7.3 原理三：为什么抖振是"必然"而非"没训好"

Eq.(28) —— 控制权重 $R\to0$ 时最优解饱和（论文未展开） $$ \mathcal{H}(x,u,\boldsymbol{\lambda})=\boldsymbol{\lambda}^{\top}(Ax+Bu)+x^{\top}Qx+u^{\top}Ru,\qquad \frac{\partial\mathcal{H}}{\partial u}=B^{\top}\boldsymbol{\lambda}+2Ru=0\Longrightarrow u^{*}=-\tfrac12R^{-1}B^{\top}\boldsymbol{\lambda} $$
关键一步：$u^*\propto R^{-1}$。当 $R\to0$（奖励里没有控制代价），$u^*$ 幅值趋于无穷，必然撞上饱和边界——这就是 bang-bang 的严格来源：不是优化器没收敛，而是最优解本身就在边界上  |  反之：只要 $R\succ0$，最优控制就是误差的连续函数（LQR 解 $u=-Kx$ 光滑），抖振自动消失。所以 PID（隐含 $R>0$）天然平滑、RL（$R=0$）天然抖——差别不在"学习能力"，而在目标函数里有没有那一项。
手段实际做了什么为什么不能根治
AVP
改奖励		加 $R_\delta\propto|\delta_t-\delta_{t-1}|$，相当于人为给了 $R>0$方向对但重新分配了权重：$c_\phi,c_\theta$ 从 0.5+0.5 变 0.25+0.25，跟踪项权重减半，于是"更平滑"部分来自"更不追求精度"（TD-MPC+AVP 的 RMSE 反而从 3.81 降到 3.58，若平滑真损精度则应上升）。且引入 3 个超参、强依赖算法，工程上不可靠。
CAPS
改正则		约束策略的 Lipschitz 常数 $\|\pi(s_t)-\pi(s_{t+1})\|_2$约束的是"策略"而非"动作"。对 PPO/SAC 二者等价；对 TD-MPC，动作来自 MPPI，策略只是 512 条中的 24 条先验——正则化对象错了，不是强度不够。
根本解
（论文未做）		要么参数化动作（输出增量 + 低通、或用样条参数化动作序列），要么部署时后置滤波（引入相位滞后、可能破坏闭环稳定），要么显式写入 $R>0$ 并接受精度损失。三条路都有人走过，但没有一条被本文验证。更彻底的是把平滑做成硬约束（CBF 安全层），把权衡从训练期挪到部署期。

7.4 原理四：湍流与阵风的信息论差别

Eq.(29)–(31) —— MDP 的两个前提与它们的失效（本笔记形式化） $$ \textbf{(P1) 马尔可夫性：}\ P(s_{t+1}\mid s_t,a_t,\mathcal{F}_{t-1})=T(s_t,a_t);\qquad \textbf{(P2) 平稳性：}\ T\ \text{不依赖于 }t $$ $$ \textbf{湍流：}\ \bar{T}(s'\mid s,a)=\lim_{T\to\infty}\tfrac1T\sum_t P(s_{t+1}=s'\mid s_t,a_t,\mathbf{v}_{w,t}),\ \ \mathbf{v}_{w,t}\sim p_w \qquad\textbf{阵风：}\ \exists t_1\neq t_2:\ P(s'\mid s,a,t_1)\neq P(s'\mid s,a,t_2) $$
湍流违反 (P1) 但满足 (P2)：Dryden 是零均值、平稳、各态历经过程，故极限 $\bar{T}$ 存在且唯一，而任何 RL 算法在有限数据下天然就是在拟合这个平均——最小化期望损失就得到 $\bar{T}$。论文原话："there exists a time-averaged MDP close to the true MDP that RL algorithms fall back into by default." 代价是策略"平均最优"、在具体某次实现下次优。
阵风同时违反 (P1)(P2)：$t_1$ 平静、$t_2$ 阵风峰值，同样的 $(s,a)$（如"滚转误差 5°、副翼满舵"）在 $t_1$ 到位、在 $t_2$ 被顶回。同样的输入、两个输出。后果：① 函数近似器被要求同时拟合矛盾目标，梯度来回翻转（"opposite updates of the function approximators occur at the onset of a wind gust"）；② 任何无记忆策略 $\pi(a\mid s)$ 无法区分 $t_1,t_2$，用 $Z\in\{0,1\}$ 表示"是否有阵风"，则 $I(a;s'\mid s)\le I(a;s'\mid s,Z)$——这就是"喂风信息（Wind Oracle）应当有效"的理论依据，而仓库里环境已写好；③ 阵风突发使 $T(\cdot,t)$ 分段，正是多模型 MDP（Steimle 2021）的适用场景。
为什么 PPO 反而最稳解释
clip 的物理意义把单次策略变化限制在 $\epsilon=0.2$ 内。梯度方向因混叠翻转时，未裁剪算法会大步朝新方向走，覆盖已学行为；PPO 每次最多走 20%，方向错了损失也有限。
on-policy 的"遗忘"优势只用当前策略的数据，旧数据（可能来自"无阵风"分布）不进梯度；SAC/TD-MPC 是 off-policy，buffer 里混着大量无阵风转移，与当前数据形成分布冲突，Q 被两种分布来回拉扯。这是 off-policy 在非平稳环境下的结构性弱点。
代价PPO 在确定性非线性下明显更差（hard 15.78 vs TD-MPC 9.10）——它学不到精确模型。PPO 的"稳"是以"钝"为代价：对环境变化不敏感，对环境结构也不敏感。这正是"鲁棒性与最优性不可兼得"的经典 trade-off。
🎯 把 7.1–7.4 串起来
TD-MPC 的强大与脆弱来自同一处：终端价值 $Q_\Theta$ 的准确性完全依赖潜空间动力学（一致性权重 20），而它是确定性映射。
  • 世界确定（hard、无风）→ 模型准 → $Q$ 准 → 规划有意义 → 赢；
  • 世界平稳随机（湍流）→ 模型学到条件均值 → $Q$ 学到平均价值 → 退化为"平均鲁棒" → 打平；
  • 世界非平稳突发（阵风）→ 模型连条件均值都学不准（$T$ 随时间跳变）→ $Q$ 系统性偏错 → 规划放大误差 → 输给最保守的 PPO。
链条每一步都能用本文数据验证，而论文只走到第一步与第三步的定性描述；中间"湍流下条件均值"那一步，它用 "on-average robust policy" 一词暗示，但没有量化验证——这正是最好的后续切入点。

10. 第一性原理推导

不从"论文做了什么"出发，而从"物理与信息的基本约束"出发，推出为什么这个问题必然长成现在这样。若推导正确，论文的实验设计、结论乃至失败都应是这些约束的推论，而非作者的个人选择。

10.1 为什么"姿态环"是唯一合理的研究切片

Eq.(32) —— 回路可分性（本笔记形式化） $$ \frac{\omega_{\text{inner}}}{\omega_{\text{outer}}}\gtrsim3\sim5\ \Longrightarrow\ \text{可分离};\qquad \frac{\omega_{\text{gust}}}{\omega_{\text{attitude}}}\approx\frac{1\text{–}4}{2\text{–}10}\sim\mathcal{O}(1)\ \Longrightarrow\ \text{不可分离} $$
姿态环 τ≈0.1–0.5 s（2–10 rad/s，因 $I_{yy}=0.1702$ 极小、俯仰响应极快）；阵风 τ≈0.25–1 s（1–4 rad/s，三段式）；空速环 τ≈0.2 s 但能量耦合 2–5 s；高度/航向 5–20 s。
结论一：姿态环与空速环带宽比 5–20，可分离——论文把空速交给独立 PI 环是正确的工程决策。结论二：姿态环与阵风带宽比 $\mathcal{O}(1)$，不可分离——阵风不是"慢变外扰"而是与控制器同频的对抗信号，任何把阵风当"准静态偏置"补偿的方法都会失效；"抗阵风"本质是带宽竞争，而舵面速率（±200°/s）与惯量给了硬上限。结论三：这正是选择姿态环而非航点跟踪的深层理由——姿态环是唯一"扰动与控制同频"的回路，最能暴露算法差异；外环扰动较慢，PID 加积分就能压住，RL 优势显不出来。

10.2 为什么小姿态角可线性化、大姿态角必然不行

Eq.(33) —— 三个被忽略项（由 Eq.3–12 展开） $$ \underbrace{\boldsymbol{\omega}\times I\boldsymbol{\omega}}_{\text{陀螺耦合}\sim\omega^2I},\qquad \underbrace{\partial C_L/\partial\alpha\ \text{的非线性}}_{\text{失速前近似线性}},\qquad \underbrace{\sin\theta,\ \cos\theta}_{\text{重力投影}} $$
① 陀螺耦合是二次项：小角速率可忽略，但 1–2 rad/s（Fig.4 的角速率子图正在此量级）时与线性阻尼项同量级，不能丢。
② 气动非线性：$C_D$ 随 $\alpha^2$ 增长、$C_l,C_n$ 的交叉导数在 $\beta\neq0$ 被激活。滚转 55° 时升力垂直分量只剩 $\cos55°\approx0.57$，$\alpha$ 必须显著增大，于是"滚转机动"被迫耦合进"俯仰/迎角"——这是几何决定的，不是控制律问题。
③ 重力投影：大角度下 $\sin\theta$ 的一阶近似误差可达 20% 以上，直接改变配平点。
综合：三项都随姿态角超线性增长，而 PID 增益是常数，故必然存在一个阈值使 PID 急剧下降——Table 2 定在滚转 45°、俯仰 25°，正是实验标定出的"线性化失效边界"（PID 4.20→20.10，4.8 倍）。

10.3 为什么确定性非线性下"模型 + 规划"必然优于"无模型"

Eq.(34) —— 两种学习对象的样本复杂度（本笔记） $$ \text{无模型：学 }\pi:\mathbb{R}^{14}\to\mathbb{R}^{2}\ \Longrightarrow\ N_\pi\sim\varepsilon^{-14};\qquad \text{基于模型：学 }d:\mathbb{R}^{14}\!\times\!\mathbb{R}^{2}\to\mathbb{R}^{14}\ \text{（仅需覆盖访问分布）} $$
为什么"同样 14 维"却更省：关键不是维度，而是"覆盖整个状态空间" vs "覆盖访问分布"。策略必须在所有可能被访问的状态上给好动作（因为误差会累积、把系统推到新状态）；动力学模型只需在策略实际走到的轨迹附近准确——而 MPPI 每步都用当前模型重新规划，误差被闭环修正。
更本质的是误差如何传播：无模型策略误差开环累积（$\pi$ 在 $s$ 处偏了，走到没学过的 $s'$，可能偏更多——正反馈）；基于模型的规划闭环修正（模型偏了 → 动作不优 → 但观测到真实 $s'$ → 下一步重规划，误差被观测打断）。这就是 TD-MPC 在 hard 下能赢的原因：它把"学习"从"必须全局正确"降级为"局部够用"。
🎯 一个可检验的预言
若上述成立，TD-MPC 相对 PPO 的优势应随"状态空间覆盖率要求"单调增长。数据正好支持：nominal（状态集中）3.81 vs 5.29 = 1.39 倍；hard（状态分散）9.10 vs 15.78 = 1.73 倍。但"增长"也可能只是"PID 退化更快"造成的假象——要真正验证，需做"状态空间覆盖率"的受控实验（固定参考幅值、只改随机性），论文没做。

10.4 为什么随机扰动下优势必然消失

Eq.(35)–(36) —— 不可约误差与偏差-方差分解（本笔记） $$ \min_{\hat{f}}\mathbb{E}\big[\ell(s',\hat{f}(s,a))\big]\ge\tfrac12H(s'\mid s,a);\qquad \mathbb{E}\big[\|\hat{T}_N-T\|^2\big]=\underbrace{\|\mathbb{E}\hat{T}_N-T\|^2}_{\text{偏差}}+\underbrace{\mathrm{Var}[\hat{T}_N]}_{\propto1/N}+\underbrace{H(s'\mid s,a)}_{N\text{ 无关}} $$
含义一（湍流）：$H>0$ 但不随时间变，故存在最优的随机预测器；用确定性模型（一致性损失）拟合它，最优解就是条件均值，残差恰为 $H$——这就是"TD-MPC 只能学到 on-average 策略"的严格来源。
含义二（阵风）：$H(s'|s,a)$ 本身依赖时间（$T=T(s,a,t)$），于是连条件均值都不是固定目标——$t_1$ 学到的在 $t_2$ 是错的。这比"熵大"严重得多：不是"学不准"，而是"没有可学的东西"。
含义三（为何 PPO 稳）：PPO 不显式建模 $T$，只做策略空间局部爬山。目标跳变时方向会错，但 clip 把每步限在 $\epsilon=0.2$，错误累积是 $O(\epsilon T)$ 而非指数级；而 TD-MPC 的模型误差经 $\gamma^HQ$ 的 97% 权重放大——模型错一点，规划错很多。
与"统一预算"的闭环：因为预算固定，偏差与方差都没消干净，无法区分"输在不可约项"还是"输在没训够"。要区分必须做样本效率曲线——正是 §9.2① 的漏洞。两个局限在此闭环。

10.5 为什么抖振是"数学必然"而非"工程缺陷"

Eq.(37) —— 最优解落在动作多面体顶点（本笔记） $$ \max_{\mathbf{a}\in[-1,1]^2}J(\mathbf{a})\ \text{且}\ J\ \text{关于}\ \mathbf{a}\ \text{单调（无控制代价）}\ \Longrightarrow\ \mathbf{a}^{*}\in\{-1,+1\}^{2} $$
论证：奖励只依赖"误差被压小的程度"、对"用了多大动作"无惩罚，则对给定状态更大动作总是（弱）更优，$J$ 关于 $\mathbf{a}$ 单调不减。单调函数在凸多面体上的最大值必在顶点，而 $[-1,1]^2$ 的顶点就是 $(\pm1,\pm1)$。
于是 bang-bang 不是"学出的坏习惯"，而是该奖励下的唯一最优解；网络连续性（tanh）只让它在顶点附近来回横跳——这就是观测到的抖振。
推论：任何"事后平滑"（低通、限幅）都是在最优解之外打补丁，必然损失性能；唯一"无损"做法是改目标使最优解不在顶点（引入 $R>0$）——AVP 正是如此，但它同时改了误差项权重，故"无损"也没做到。CAPS 走另一条路：不动目标，而限制策略类的表达能力（Lipschitz 约束），使顶点解不可达。两条路哲学完全不同，这解释了适用面差异。

10.6 为什么"训练见过各种扰动"不等于鲁棒

Eq.(38) —— 域随机化的两个隐含假设（本笔记） $$ \textbf{(A1) 支撑覆盖：}\ \mathrm{supp}(p_{\text{test}})\subseteq\mathrm{supp}(p_{\text{train}});\qquad \textbf{(A2) 单峰性：}\ p_{\text{test}}\ \text{与}\ p_{\text{train}}\ \text{同属一个模式} $$ $$ \pi^{*}_{\text{single}}=\arg\max_\pi\mathbb{E}_Z[J(\pi\mid Z)]\ \neq\ \mathbb{E}_Z\big[\arg\max_\pi J(\pi\mid Z)\big]=\pi^{*}_{\text{multi}} $$
(A1) 成立：训练风速 $U[0,23]$ m/s 覆盖测试的 0/7/15/23，方向覆盖 $[-1,1]$——"没见过"不是问题。
(A2) 不成立：阵风使环境双峰——"平静"与"阵风"是两个截然不同的动力学。用一个策略同时拟合，最优解只能是两者折中，而折中在任一模式下都不是最优。期望的最优 ≠ 最优的期望（Jensen）：平均策略的期望回报严格低于"按模式切换的最优策略"，除非两模式恰好共享最优策略。这就是"阵风下劣势消失"的第一性原理根源，也是"喂风信息应当有效"的依据。

控制器它假设了什么何时赢何时输本质代价
PID可线性化、轴间解耦、扰动准静态小姿态角、标称风况大姿态角、快变扰动假设最强 → 最稳但上限最低
PPO策略可在一连续函数类内逼近；信赖域够小非平稳、需要保守需要精确非线性无模型 → 只能局部爬山，学不到结构

🎯 全文的第一性原理总结
控制器的性能上限，由"建模假设与真实环境的同构程度"决定，而非"拟合能力有多强"。
PID 假设线性+解耦，nominal 下成立 → 强基线；大姿态角不成立 → 退化 4.8 倍。
TD-MPC 假设确定性可学模型，hard 下成立 → 赢 2.2 倍；阵风下不成立 → 输给最保守的 PPO。
PPO 几乎不假设结构 → 所有场景"不最差"但也"不最好"（hard 15.78，比 TD-MPC 差 73%）。
所以本文测的不是"哪个算法更好"，而是"在什么假设下哪个算法更好"。标题写的是 "Model-Free versus Model-Based"，读完后你会发现真正的自变量是"环境是否满足模型的假设"。

11. 核心要点

11.1 经验教训

层面教训具体内容
方法论把"预算"写成硬约束本文最扎实之处：所有 agent 750k 步、5 次运行、均值 ± SEM，且逐项落在 Table 3/4/5 里。对比实验最容易失控的就是预算，写进配置表而非正文，是让结论站住的最低成本手段。
把困难拆成可分离的自变量风拆成常值/湍流/阵风，参考拆成 nominal/hard，且风实验固定在 nominal 参考——让"扰动效应"与"难度效应"不混淆。任何鲁棒性评测都应自问：我有没有同时变动两个因素？
负面结果要单独成段最有价值的结论（"阵风下 RL 优势有限"）只以从句出现在贡献列表，正文无专节——这是遗憾。负面结果标定了适用边界，信息量常大于正面结果。
技术终端价值是可复用的设计模式任何"短视界规划 + 学到的价值函数"都可用 Eq.17 的 $\gamma^HQ$ 补尾巴，把"规划视界"与"有效视界"解耦——$H=3$ 的计算量换无限时域近似。可直接搬到视觉伺服、拦截末制导等短时域任务。
正则化必须作用在被执行的函数上"CAPS 对 TD-MPC 无效"是一条通用教训：分层/混合架构里策略只是"提议分布"，真正决定动作的是规划器或滤波器。这个坑在 actor-critic + MPC、RL + 安全层里普遍存在。
确定性模型在随机环境退化为条件均值凡用确定性潜动力学 + MSE/一致性损失的 MB-RL，在随机环境都会遇到。解法只有两条：模型改成概率的，或把随机性显式建模成隐变量（RSSM）。
写作标题与内容错位标题是 "Model-Free versus Model-Based"，但真正的自变量是"环境是否满足建模假设"。更好的标题应体现"确定性 vs 随机性"——那才是结论的分水岭。
用词要与效应量匹配9.3% 的差距叫 "slightly better"，2.2 倍的差距叫 "significant advantage"——这是全文表达上最专业的地方，值得学习。

11.2 对我的研究可直接应用（UAV 视觉伺服 / 拦截 / 敏捷飞行）

场景为什么本文直接相关可直接搬的三件事 / 必须补的
拦截末制导末段特点与 hard 参考高度同构——确定性、强非线性、短时域、对精度极敏感，正是 TD-MPC 的优势区（§10.3）① 用 Eq.17 的终端价值替代"有限时域打靶"，把剩余飞行时间映射到 $\gamma^H$；② 用 MPPI 替代 iLQR/GPOPS（饱和与失速是非光滑约束）；③ 把 Act Fluct 写进评价（末段舵机是"一次性"的）。必须补：目标机动是对抗性的，域随机化框架不够用，需博弈/鲁棒 RL
视觉伺服核心困难是观测延迟 + 遮挡 + 状态不可观测，与"阵风→POMDP"在数学上同类（§7.4）① 用本文的诊断法先判断"延迟是平稳（类湍流）还是突发（类阵风）"——前者可帧堆叠硬扛，后者必须上记忆；② 把 Wind Oracle 思路改成"延迟/位姿 Oracle"，先定性能上界再决定值不值得做估计器；③ 打开 CAPS 的 $L_{SS}$ 并把 $\sigma$ 调大（本文没用，但它正是为噪声设计的）。必须补：本文观测是真值 14 维，视觉伺服多一层估计器，端到端的样本复杂度不同
敏捷飞行 / 大机动hard 参考（55°/28°）已接近敏捷姿态，本文证明该区间 PID 退化 4.8 倍——这是最直接的动机证据① "确定性非线性 → 用 MB-RL"这条判据，敏捷飞行优先 TD-MPC 而非 PPO；② 把 AVP 作默认配置（唯一双赢的配置是 TD-MPC+AVP）；③ 直接用 100 Hz + 20 s 协议做可比基线。必须补：本文参考是阶跃，敏捷是时变轨迹，需前馈与相位补偿——本文架构里没有
通用实验设计三个可直接抄的设计① "难度×扰动"全矩阵（2×4）：本文把风固定在 nominal 以隔离变量，反过来做全矩阵就能看出是否存在交互效应；② 双指标报告（精度 + 平滑）；③ 5 次 + SEM + 标注单位（本文在单位上翻车，零成本可避免）。反面教材：统一 750k 预算却放弃样本效率曲线，必被审稿人质疑
💡 如果只从本文拿走一件事
拿走这个判据：先判断环境属于"确定性非线性"还是"随机/非平稳"，再决定用 MB-RL 还是 MF-RL。
  • 确定性 + 非线性强 → TD-MPC（模型能学准、规划能发挥作用），配 AVP 压抖振；
  • 随机但平稳（类湍流）→ PPO 或 TD-MPC 都行，别指望算法带来数量级提升，把精力花在提高控制器带宽上；
  • 突发非平稳（类阵风/遮挡/对抗）→ PPO + 记忆（RNN）是最稳的起点，且必须显式建模"模式"（先用 oracle 实验定上界）。
这个判据不是笔者的发明，而是本文四组实验与第 10 节推导共同指向的结论。它比"RL 比 PID 好"有用得多。

11.4 三句话总结

🎯 如果只能记住三句话
① 确定性非线性下，学一个模型再规划确实能打败 PID 与无模型 RL——hard 参考下是 2.2 倍与 1.7 倍的差距。
② 但这优势完全建立在"模型能学准"上：环境一旦随机（湍流）或非平稳（阵风），确定性模型退化为条件均值甚至失去意义，TD-MPC 的优势消失、甚至被最保守的 PPO 反超。
③ 而所有 RL 方法（MF 与 MB）都有共同的、被长期忽视的代价：动作抖振比 PID 高 1–2 个数量级，且现有手段（AVP/CAPS）只能压到 PID 的 7 倍，压不下去。
